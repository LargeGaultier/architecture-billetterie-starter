# Usage de l'IA pendant les ateliers

L'IA peut aider à explorer des options, générer du code et relire des tests. La responsabilité du choix et des garanties reste à l'équipe.

Pour chaque usage significatif, conservez une trace courte :

| Question posée | Proposition de l'IA | Décision de l'équipe | Vérification réalisée |
| --- | --- | --- | --- |
| … | … | … | test, mesure, lecture du code ou source |

Demandez plusieurs options avec leurs coûts. Vérifiez sur le cas de la billetterie les invariants, la concurrence, les états incertains et le comportement en panne. Une réponse convaincante ne remplace pas une preuve reproductible. Dans l'ADR, expliquez ce que vous avez retenu et pourquoi.
